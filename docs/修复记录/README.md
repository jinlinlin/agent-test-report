# 修复记录

本目录记录每次改动"做了什么、动了哪些文件"。

## 生成方式（当前约定，已弃用 git 钩子）
当用户要求 Agent **编写 commit** 时，Agent 按顺序：
1. 先依据本次要提交的暂存改动，在此目录生成一份修复记录；
2. 把**代码改动 + 这份记录一起 `git add`**；
3. **一笔 commit 整体提交**（记录与代码同属一笔提交，不再产生跟随提交）。

## 命名
`YYYYMMDD-HHMMSS.md`，一次提交对应一份，互不覆盖。
> 因记录是在提交**之前**生成的，一笔提交无法包含它自身的 commit SHA，故文件名与正文只带时间戳、不带自身哈希。

## 每份记录包含
- 生成时间 / 作者
- 本次提交说明（取自拟定的 commit message）
- 变更文件（name-status）
- 变更统计（diffstat）

## 注意
- 记录由 Agent 在"写 commit"这步生成；若用户自行手动提交，则不会自动生成（可另行让 Agent 补一份）。
- 历史上文件名带 `-<短提交号>` 后缀的记录，由早先的 `post-commit` 钩子自动生成，作为历史保留，机制现已移除。
